01 / 04
工作台 · 首页
用户进入产品的第一站。粘贴商品链接即可一键启动批量生成,数据概览前置展示哪条素材在赚钱,待优化模块基于回流数据自动诊断疲劳/爆款。
01 · Home
关键交互:顶部快速粘链接区可直接启动 → 跳转生成向导;数据概览支持今日/7天/30天切换;ROI 趋势小图按批次聚合;待优化卡按风险等级红/黄/绿分级,一键克隆爆款 / 重做疲劳款。
02 / 04
视频生成主流程 · 5 步向导
粘链接 → 商品确认 → 选脚本 → 生成中 → 选片导出。最少决策点的引导式流程,每一步都可批量化,Credits 消耗实时透明,合规风险分级提示。
02-1 · 粘链接(解析中)
关键交互:支持淘宝/天猫/京东/拼多多/抖店全平台链接;解析中显示 4 阶段进度(抓取页面 → 解析图文 → 识别卖点 → 生成商品卡),每个阶段独立动画 + 状态标识。
02-2 · 商品确认 + 卖点采集
关键交互:左侧 8 张商品图可拖拽排序、删除;右侧 6 条 AI 提取卖点可勾选、编辑、自定义补充;极限词预警("最佳"、"第一"、"治疗") 红色 chip 标注,点击可一键改写。
02-3 · 选脚本 + 模型 + 参数
关键交互:6 种脚本风格(痛点/种草/直给/测评/口播/剧情)× N 数量(支持 1~30 条)× 模型档位(基础 / 高清 / 旗舰),底部 Credits 实时计算且高亮显示总消耗;余额不足时按钮拦截 + 充值入口。
02-4 · 批量生成中(用户最焦虑环节)
关键交互:顶部环形总进度 + 已完成数 + 预计剩余时间;每条任务独立卡片显示 4 阶段(脚本 → 渲染 → 编码 → 完成),状态色区分;失败任务可重试,允许用户离开页面后台继续。
02-5 · 选片导出
关键交互:9:16 视频网格布局,每张含 AI 评分(画质/卖点契合/合规)+ 时长 + 模型来源;合规分级:低风险弱提示,高风险红色拦截弹窗,需确认才能导出;sticky 底栏支持批量下载/送审/直接对接广告后台。
03 / 04
我的素材 · 素材库
已生成的所有素材集中管理,支持卡片/列表两种密度。投放数据(CTR/ROI)直接挂在素材上,爆款一键克隆为新批次。
03-1 · 卡片视图
关键交互:卡片显示视频缩略图、状态徽章(草稿/已投放/爆款/疲劳)、CTR/ROI 内联指标;hover 显示快捷操作;支持多选 → 浮现底部批量操作浮条(克隆/导出/送审/删除)。
03-2 · 列表视图
关键交互:同样数据的高密度展示,适合批量审核场景;每行显示完整指标列(消耗/GMV/ROI/CTR/CVR),支持排序和列筛选。
04 / 04
数据回流 · 投放看板
已对接巨量引擎、磁力金牛等第三方广告平台。把"哪条素材能赚钱"放在最显眼位置,AI 诊断给出可执行的下一步动作。
04-1 · 投放总览
关键交互:多平台连接卡(巨量/磁力/视频号/快手),已授权显示同步状态;转化漏斗(曝光 → 点击 → 加购 → 成交),每节点漏失率高亮;底部 Top 素材排行榜按 ROI 降序。
04-2 · AI 诊断
关键交互:AI 自动识别四类问题素材(疲劳款 / 低曝光 / 高 CTR 低 CVR / 跑量饱和),每类给出具体诊断 + 一键操作(暂停 / 衍生新批次 / 加大投放)。
04-3 · A/B 对比
关键交互:选取 2 条同源素材并排对比所有指标,差异值高亮;AI 给出一句话结论;可基于优胜者一键克隆衍生 5 条变体继续 A/B。
